## 1. La solución: no hacía falta `df.coord`

P1.6 se quedó bloqueado intentando construir un `df.coord`. **El problema era
la pregunta equivocada.** La documentación **de la versión instalada** dice:

```
Lua API.txt:2357:  "dfhack.maps.forEachTile(bounds[, filter[, actions]])"
Lua API.txt:2365:  The bounds argument may be given as a "{x1,y1,z1,x2,y2,z2}"
                   table ... The cuboid is clamped to the loaded map and tiles
                   in unallocated map blocks are skipped.
```

**`bounds` es una tabla Lua simple `{x1,y1,z1,x2,y2,z2}`. No hace falta ningún
objeto `df.coord`.** Y el cúbide **se recorta solo** al mapa cargado: no se puede
leer fuera de límites.

```
dfhack.maps.forEachTile(bounds [, filter [, actions]])
  bounds  = {x1,y1,z1,x2,y2,z2}
  filter  = fn(x,y,z,block,localx,localy,tiletype)  |  nil
  actions = { callback = fn(...) }                  |  fn  |  nil
  devuelve { scanned, matched, changed, constructed, aborted }
```

La API está marcada como **experimental** en la documentación. Se anota.

**`getBiomeType(x,y,z)` devuelve un BOOLEANO, no un identificador de bioma.**

El prototipo lo emitía como `bioma_num: true`. **No se ha interpretado qué
significa** el booleano: se registra tal cual.

prototipo lo descarta con un guardián de tipos y lo declara `null`.

## 7. Lo que NO se hizo

| Punto | Estado |
|---|---|
| Distinguir visibilidad actual de conocimiento histórico | **NO DEMOSTRADO** |
| Tile explorado pero no visible ahora | **NO** |
| Tile nunca explorado | **NO** |
| Geología, minerales, recursos | **Fuera de alcance** |

### El límite importante (Fase D incompleta)

**`isTileVisible` responde a «¿lo ve el jugador AHORA?», no a «¿lo ha visto
alguna vez?».**

Las cuatro categorías que pedía la misión **no se pueden distinguir con lo
demostrado**. `isTileVisible == false` significa *ahora no*; podría estar oculto
por niebla en un terreno que el jugador conoce de memoria.

**Se declara:** DFHack **no ha demostrado** aquí un mecanismo para distinguir
visibilidad actual de conocimiento histórico.
