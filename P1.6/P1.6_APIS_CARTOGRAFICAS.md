## 2. Hallazgo principal: `isTileVisible`

```
dfhack.maps.isTileVisible(x, y, z)
```

**El mismo patrón que `dfhack.units.isVisible(u)` de P1.5.**

Eso permite construir la frontera de conocimiento del mapa sobre una regla del
**propio juego**, en vez de sobre una lista de excepciones inventada:

```
leer el tile  ⟶  isTileVisible == false  ⟶  NO se emite
```

| Dato interno | ¿El jugador lo ve? |
|---|---|
| `getTileType` (tipo de terreno) | **Depende**: solo en zona explorada |
| `getBiomeType` (bioma) | **Depende**: el bioma se ve al explorar |
| `getTileFlags` | Parcialmente: banderas de diseño |
| `getRegionBiome` | **CONDICIONAL**: requiere mapa regional |
| `getLocalInitFeature` / `getGlobalInitFeature` | **CONDICIONAL**: rosa de los vientos |

**Ningún dato cartográfico se clasifica `VISIBLE` sin pasar por
`isTileVisible`.** Un tile no explorado devuelve información que el jugador no
tiene.
