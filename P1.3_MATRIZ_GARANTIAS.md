## 4. Garantías REFUTADAS

| # | Garantía que se creía | Por qué es falsa | Hipótesis |
|---|-----------------------|------------------|-----------|
| R1 | `dataset_id` identifica el estado | Es hash de contenido | H-001 |
| R2 | El tick identifica el estado | Se reinicia cada año y retrocede | H-002 |
| R3 | `mundo + año + tick` identifica el estado | No detecta ramas; la carpeta es duplicable | H-003 |
| R4 | `sha256(world.sav)` identifica el save | Copia byte a byte → mismo hash | H-004 |
| R5 | `world_folder` identifica el estado | La carpeta contiene todos los estados | H-005 |
| R6 | `mtime` identifica el estado | Depende de la copia, no del contenido | H-007 |
| R7 | El XML exportado es un snapshot | Cesión por elemento y por chunk | H-010 |
| R8 | `region1` + `region2` son un estado | Dos contenedores independientes | H-013 |
